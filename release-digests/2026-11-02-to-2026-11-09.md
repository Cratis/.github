The compiler reports `PLAY0950` for a line without a path and `PLAY0951` for an image that is not PNG, JPG, GIF, SVG or WebP or a mockup that is not an HTML page; opening a model root (CLI, MCP) warns with `PLAY0952` about a file that is missing or outside the root. The event model board draws a placed event again with `sourceEventId` pointing at its declaration and lists placed read models on the slice; renaming the declaration renames every placement. `PLAY0953` refuses a malformed line, `PLAY0954` warns about an unknown element and `PLAY0955` about an element the slice already declares or shows twice. See [Show an element in more than one slice](https://github.com/Cratis/Screenplay/blob/main/Documentation/screenplay/slices.md#show-an-element-in-more-than-one-slice). (#1193)
