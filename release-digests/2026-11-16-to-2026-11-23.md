- **AI** ([Release v7.178.2](https://github.com/Cratis/AI/releases/tag/v7.178.2)): Restricted sessions block a `read`, `grep`, `find` or `ls` tool that another extension registers or overrides, and allow only Pi's built-in tools (#1291)
- **AI** ([Release v7.178.2](https://github.com/Cratis/AI/releases/tag/v7.178.2)): Restricted reads stay inside the session workspace after resolving symlinks. Paths that escape and malformed arguments are refused (#1291)
- **AI** ([Release v7.178.2](https://github.com/Cratis/AI/releases/tag/v7.178.2)): Restricted `grep` is refused while a ripgrep configuration file is set, because that configuration could follow links out of the workspace or run commands (#1291)
- **Chronicle.Go** ([Release v0.17.2](https://github.com/Cratis/Chronicle.Go/releases/tag/v0.17.2)): Decoding an event at a generation other than the one the kernel delivered now returns an error wrapping `ErrUnsupported` when any registered generation of that event type has `pii` or `encrypted` fields, instead of decoding ciphertext into fields typed as plaintext. The kernel does not yet release protected values for other generations (https://github.com/Cratis/Chronicle/issues/4623) (#90)
- **Chronicle.Go** ([Release v0.17.2](https://github.com/Cratis/Chronicle.Go/releases/tag/v0.17.2)): Reactors and reducers that handle a historical generation of a protected event type are refused when they are registered, and delivery refuses such content before any handler runs

- **Stage** ([Release v6.2.3](https://github.com/Cratis/Stage/releases/tag/v6.2.3)): Pull request CI now takes its routing and gate decisions from the target branch's tooling, unpacked into a separate temporary folder, instead of from the pull request's own copy.
